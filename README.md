# Ocean GIS fieldbook

Pre-season work (2026) building hands-on fluency in GIS, Python and Earth observation data, on the way to a public product on Global Fishing Watch APIs.

Site used throughout: **Acantilados y Fondos Marinos de La Punta de La Mona**, a marine Special Area of Conservation on the Granada coast (WDPA id 555523929).

| Folder | What it shows |
|---|---|
| `03-vector-mpa/` | Loading a real MPA boundary from an Esri File Geodatabase with GeoPandas |
| `04-raster-cog/` | Reading a 305.6 MB Sentinel-2 Cloud-Optimized GeoTIFF by moving 32 KB, plus a QGIS map of the MPA on top |
| `formats-in-my-own-words.md` | Vector and raster formats explained for a non-GIS colleague |

Data files are not stored here. Each `data/SOURCE.md` says where the data comes from and under what licence.
